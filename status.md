## ✅ Завершено

- ✅ `index.html` — одностраничный лендинг (hero, услуги, география, галерея, тарифы, GPS-демо, форма заявки, футер)
- ✅ SEO-теги, Open Graph, canonical

- ✅ `telegram-bot.py` — Flask backend, пересылающий заявки в Telegram
- ✅ `INSTALLATION.md` — полное руководство по настройке

## 🔧 Что нужно сделать перед публикацией

По `INSTALLATION.md`:
1. [ ] Получить `BOT_TOKEN` у @BotFather
2. [ ] Получить `CHAT_ID`
3. [ ] Вставить реальные значения в `telegram-bot.py`
4. [ ] Запустить backend (`pip install -r requirements.txt && python telegram-bot.py`)
5. [ ] Развернуть сайт на хостинге (Vercel/VPS) и указать реальный `API_URL` в `index.html`, если backend на другом домене
